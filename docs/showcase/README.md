# Galeria de apresentação do Meu Zé

Esta pasta contém artes de documentação criadas especificamente para a página pública do projeto.

| Arte | O que representa |
| --- | --- |
| `hero.svg` | Capa retro/editorial do Meu Zé 2.0 |
| `feed.svg` | Feed com publicações de exemplo |
| `chat.svg` | Conversas simuladas no visual retro |
| `profile.svg` | Exemplo de perfil personalizável |
| `themes.svg` | Presets de cores e estilos |

**IMPORTANTE:** são **mockups ilustrativos**, e **não capturas reais** dos usuários, servidores ou mensagens da rede. Os nomes Lia, Bento e Nina e todas as frases nos desenhos representam cenários fictícios, inclusive quando semelhantes aos dados de demonstração já existentes no código. Horários e contagens são ilustrativos.

## Adicionar capturas reais no futuro

1. Utilize uma conta de demonstração, sem dados privados, em uma instalação autorizada.
2. Não exponha perfis de amigos, e-mails, contatos, tokens, convites ou conversas privadas.
3. Salve as capturas reais em `docs/screenshots/` e identifique aplicativo, versão e dispositivo.
4. Atualize o README para diferenciar capturas autênticas dos mockups.
