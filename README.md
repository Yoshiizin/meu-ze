# 🦕 Meu Zé — a internet é nossa

Rede social privada para nossa galera.

## 📲 Baixar aplicativo

### Android
**[⬇️ Baixar Meu Zé para Android (APK)](https://github.com/Yoshiizin/meu-ze/releases/latest/download/Meu-Ze.apk)**

Ou abra a página **[Releases — downloads do Meu Zé](https://github.com/Yoshiizin/meu-ze/releases)** e toque em **Meu-Ze.apk**, na seção **Assets**. Este repositório é privado: é necessário estar logado no GitHub e ter acesso.

Instalação: baixe o APK no Android 10 ou superior, abra o arquivo e autorize a instalação se o sistema pedir. Esta é uma versão de teste assinada com chave temporária; atualizações podem exigir reinstalação.

### iPhone
Abra **[meu-ze.vercel.app](https://meu-ze.vercel.app)** no Safari → **Compartilhar** → **Adicionar à Tela de Início**. O app instalado usa o mesmo site, conta e conversas.
